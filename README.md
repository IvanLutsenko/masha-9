# Маше 9 — приглашение в Лагерь полукровок

Статика (GitHub Pages) + бэкенд на Google Apps Script над Google-таблицей.

- `index.html` — приглашение, RSVP, вишлист с бронью. Именная ссылка: `…/#Соня`.
- `admin.html` — штаб для родителей (по PIN): регистрации, кто что дарит, «Освободить».
- `config.js` — URL бэкенда, время, место, список подарков и ссылки на Kaspi.
- `apps-script/Code.gs` — бэкенд.

Без `scriptUrl` сайт работает в демо-режиме (ничего не сохраняет).

## Бэкенд
Apps Script, привязанный к Google-таблице, деплой через clasp из папки с `Code.gs`, `appsscript.json` и `Secrets.gs`.

1. `Secrets.gs` (не в git): `const ADMIN_PIN = '…';` — без него админка не откроется.
2. `clasp push -f && clasp update-deployment <deploymentId>` — URL веб-приложения не меняется.
3. В `appsscript.json` должен быть блок `webapp` (`ANYONE_ANONYMOUS`, `USER_DEPLOYING`).
4. Новый подарок в `config.js` → добавить его id в `ALLOWED_IDS` в `Code.gs` и передеплоить.

Защита: брони только для id из `ALLOWED_IDS`, не больше 20 броней за 10 минут, PIN блокируется на 15 минут после 5 неверных попыток.

## Что видно публично
Только какие подарки заняты (без имён). Имена, телефоны и комментарии — только в таблице и в `admin.html` по PIN.
Список гостей в репозитории не хранится: имя берётся из ссылки (`#Соня`, `#Прохор+Вера`).
