# Маше 9 — приглашение в Лагерь полукровок

Статика (GitHub Pages) + бэкенд на Google Apps Script над Google-таблицей.

- `index.html` — приглашение, RSVP, вишлист с бронью. Именная ссылка: `…/#Соня`.
- `admin.html` — штаб для родителей (по PIN): регистрации, кто что дарит, «Освободить».
- `config.js` — URL бэкенда, время, место, список подарков и ссылки на Kaspi.
- `apps-script/Code.gs` — бэкенд.

Без `scriptUrl` сайт работает в демо-режиме (ничего не сохраняет).

## Бэкенд (≈3 мин)
1. Создать пустую Google-таблицу → Расширения → Apps Script.
2. Вставить `apps-script/Code.gs`, сохранить.
3. Выбрать функцию `setup` → Выполнить → дать доступ. В журнале будет `ADMIN_PIN = ####`
   (поменять: Настройки проекта → Свойства скрипта → `ADMIN_PIN`).
4. Начать развёртывание → Новое → Веб-приложение: «Выполнять от имени: я», «Доступ: все».
5. URL `…/exec` вставить в `config.js` → `scriptUrl`.

После правок `Code.gs` — «Управление развёртываниями» → редактировать → «Новая версия» (URL сохранится).

## Что видно публично
Только какие подарки заняты (без имён). Имена, телефоны и комментарии — только в таблице и в `admin.html` по PIN.
Список гостей в репозитории не хранится: имя берётся из ссылки.
